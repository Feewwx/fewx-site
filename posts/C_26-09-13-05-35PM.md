## # 和 ##

### `#` 把参数变成字符串

```c
#define STR(x) #x

printf("%s\n", STR(hello));     // 打印 hello
printf("%s\n", STR(1 + 2));     // 打印 1 + 2,原样,不计算
```

最常用的写法 - 连变量名一起打印出来,省得手写:

```c
#define PRINT_INT(x) printf(#x " = %d\n", x)

int score = 95;
PRINT_INT(score);               // 输出: score = 95
```

### `##` 把两个记号粘成一个

```c
#define CAT(a, b) a##b

int CAT(my, Var) = 10;          // 等价于 int myVar = 10;
printf("%d\n", CAT(my, Var));   // 输出 10
```

用在批量生成名字:

```c
#define MAKE_GETTER(type, name) \
    type get_##name(void) { return name##_value; }
```

### 一个坑

如果宏的参数本身也是个宏,`#` 和 `##` 拿到的是**没展开的原文**.想让它先展开,得再套一层宏.
