## 结构体实现位段

```c
#include <stdio.h>

struct A {  // 位段的类型只能是整型,且不能混用
    // 后面的数字不能大于成员类型的大小(int:32bit,char:8bit)
    // 发现成员类型均为int,先拿四字节
    // 4byte - 32bit
    int a : 2;   // 32 - 2 = 30
    int b : 5;   // 32 - 5 = 27
    int c : 10;  // 32 - 10 = 22
    // 不够了,再拿四字节
    // 4byte - 32bit
    int d : 30;  // 32 - 30 = 2
};

int main() {
    printf("%d\n", sizeof(struct A));  // 8
    struct A a = { 0 };
    a.a = 10;
    // 10的二进制是1010,因为只分配了2bit,所以实际存储的是10
    // 0000 0000 0000 0000 0000 0000 0000 00|10
    a.b = 12;
    // 12的二进制是1100,分配5bit,实际存储内容01100
    // 0000 0000 0000 0000 0000 0000 0|011 00|10
    a.c = 3;
    // 3的二进制是11,分配10bit,实际存储内容0000000011
    // 0000 0000 0000 000|0 0000 0001 1|011 00|10
    a.d = 4;
    // 4的二进制是100,分配30bit,实际存储内容...00000000100
    // 00|00 0000 0000 0000 0000 0000 0000 0100
    return 0;
}
```

**!!位段的跨平台问题!!**

- int位段被当成有符号数还是无符号数存储是不确定的

- 位段中最大位数的数目不能确定(16位机器最大16bit,32位机器最大32bit)

- 位段中的成员在内存中是从左向右分配还是从右向左分配标准尚未定义

- 当一个结构包含两个位段,第二个位段成员是否能利用第一个位段剩余的空间,尚未定义

**总结:**

- 和结构相比,位段可以达到同样的效果,可以很好的节省空间,但是有跨平台问题的存在

> 位段在网络中使用较多
