## define 定义常量和宏

### 预定义符号

```c
__FILE__  // 进行编译的源文件

__LINE__  // 文件当前的行号

__DATE__  // 文件被编译的日期

__TIME__  // 文件被编译的时间

__STDC__  // 如果编译器遵循ANSI C标准,则为1,否则未定义
```

举个例子

```c
printf("file:%s line:%d\n", __FILE__, __LINE__);
```

### define 定义标识符常量

### 基本用法

```c
#define MAX 100
#define NAME "fewx"

int main() {
    int arr[MAX];                  // 能用,预处理阶段已经换成字面量 100
    printf("%d %s\n", MAX, NAME);
    return 0;
}
```

`MAX` 到编译器那儿已经变成字面量 `100` 了,类型是 `100` 自己的类型(int),跟 define 没关系.

### 和 const 的区别

```c
const int max = 100;   // 有类型,编译器会检查,能取地址
#define MAX 100        // 纯文本替换,没有类型这回事
```

- **const:** 是变量,只是不能被改.占内存,有类型
- **define:** 不是变量,预处理阶段就被抹掉了.不占内存,没类型

### define 定义宏

### 基本用法

```c
#define ADD(x, y)  ((x) + (y))
//      宏名 参数(无类型)  宏体

int Add(int x, int y) { return x + y; }   // 函数
```

宏的参数**没有类型**,预处理器只认名字,你把 `"abc"` 传进去它也照换.

### 和函数的区别

|              | 宏                 | 函数         |
|--------------|--------------------|--------------|
| 什么时候处理 | 预处理(纯文本替换) | 编译         |
| 类型检查     | 没有               | 有           |
| 调用开销     | 没有               | 有(压栈跳转) |
| 能调试吗     | 展开后就看不见了   | 能           |
| 能取地址吗   | 不能               | 能           |

宏在 `gcc -E` 那一步就已经消失,`test.i` 里只剩展开后的文本.

### 坑一:参数不加括号

```c
#define SQUARE(x) x*x
SQUARE(1+2)                  // 展开成 1+2*1+2 = 5,不是 9

#define SQUARE(x) ((x) * (x)) // 正确:每个参数一层括号,整体再来一层
```

### 坑二:参数被求值多次

```c
#define MAX(a, b) ((a) > (b) ? (a) : (b))
MAX(i++, j++)                // 大的那个会自增两次
```

函数不会有这问题,参数只求值一次.这是宏的死穴.

### 坑三:多条语句要包 do{}while(0)

```c
#define PRINT(x) do { printf("%d\n", x); printf("done\n"); } while (0)

if (cond)
    PRINT(5);                // 不包的话只有第一句受 if 管,后面几句无条件执行
else
    ...
```

为什么不直接一对花括号:因为你用的时候习惯在后面加分号,`{...};` 那个分号会把 if 提前结束掉,后面的 else 就废了.do-while(0) 后面跟分号是合法的.

### 两条书写规矩

- **宏体末尾不写分号** - 分号由使用者写,免得展开后多出一个空语句
- **多行宏用反斜杠 `\` 续行** - 反斜杠后面不能有任何字符,空格,Tab 都不行
