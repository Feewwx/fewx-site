## strcmp函数

```c
#include <stdio.h>
#include <string.h>

int main() {
    char arr1[20] = "zhangsan";
    char arr2[] = "zhangsanfeng";
    int ret = strcmp(arr1, arr2);
    if (ret < 0)
        printf("arr1 < arr2\n");
    else if (ret == 0)
        printf("arr1 == arr2\n");
    else
        printf("arr1 > arr2\n");
    return 0;
}
```

> strcmp 函数会将两个字符串进行逐字符对比,如果相等则返回0,如果字符串1中的字符大于字符2中同位置的字符,则返回1,否则返回-1

- 比的是 ASCII 值

> 模拟实现

```c
#include <stdio.h>

int my_strcmp(char *arr1, char *arr2) {
    while (*arr1 == *arr2) {
        if (*arr1 == '\0')
            return 0;
        arr1++;
        arr2++;
    }
    return (*arr1 - *arr2);
}

int main() {
    char arr1[] = "abc";
    char arr2[] = "abx";
    int ret = my_strcmp(arr1, arr2);
    if (ret < 0)
        printf("arr1 < arr2\n");
    else if (ret == 0)
        printf("arr1 == arr2\n");
    else
        printf("arr1 > arr2\n");
    return 0;
}
```
