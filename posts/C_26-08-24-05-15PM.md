## 枚举

### 枚举类型的定义

```c
#include <stdio.h>

enum color { RED, GREEN, BLUE };

enum sex { MALE = 1, FEMALE };

int main() {
    printf("%d\n", RED);     // 0
    printf("%d\n", GREEN);   // 1
    printf("%d\n", BLUE);    // 2

    printf("%d\n", MALE);    // 1
    printf("%d\n", FEMALE);  // 2
    return 0;
}
```

### 枚举的优点

- 增加代码的可读性和可维护性

- 和#define定义的标识符比较,枚举有类型检查,更加严谨

- 防止了命名污染(封装)

- 便于调试

- 使用方便,一次可以定义多个常量

### 枚举的使用

```c
enum color { RED = 1, GREEN = 2, BLUE = 4 };

int main() {
    enum color g = GREEN;  // 创建变量g并赋值为GREEN
    g = 4;  // 值从GREEN变为4
    return 0;
}
```
