## 编译和链接

源文件 ---编译器---> 目标文件 ---链接器---> 可执行文件

```bash
gcc -E a.c -o a.i     # 预处理:展开头文件,展开宏,去掉注释
gcc -S a.i -o a.s     # 编译:变成汇编
gcc -c a.s -o a.o     # 汇编:变成目标文件(这一步产出 .o)
gcc    a.o -o a       # 链接:和别的 .o,库合起来,变成可执行文件
```

编译 -S 词法/语法/语义分析,符号汇总
汇编 -c 形成符号表     
链接    符号表的合并和重定位      

含有多个源文件是怎么编译的,如何规划好多个文件里的函数的

符号表就起了这个作用
