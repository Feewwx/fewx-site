## 条件编译

### `#if` 的基本形式

```c
#if 表达式
    ...
#elif 另一个表达式
    ...
#else
    ...
#endif          // 必须收尾,少一个就报错
```

判断依据只能是**编译期常量**(宏,整数).变量不行,预处理器不认识变量:

```c
#if x > 0        // x 是变量 → 直接报错
```

### `#ifdef` 和 `#ifndef`

只看"这个名字定义过没有",不管它的值是多少:

```c
#ifdef  名字     // 定义过 → 留下
#ifndef 名字     // 没定义过 → 留下
```

注意一个坑:**没定义过的宏,在 `#if` 里一律当成 0.**

```c
#if FOO          // FOO 没定义 → 当成 0 → 整段丢掉
    ...
#endif

#define FOO 1    // 写在这儿太晚了,上面早算完了
```

### 和 if 语句的区别

|              | if 语句               | #if                  |
|--------------|-----------------------|----------------------|
| 什么时候判断 | 程序运行时            | 编译之前(预处理阶段) |
| 判断依据     | 变量,运行结果         | 只能是宏和整数       |
| 没选中的代码 | 还在程序里,运行时才跳 | 直接从代码里消失     |

### 用处一:头文件保护

```c
#ifndef COMMON_H
#define COMMON_H

struct Point { int x, y; };

#endif
```

防止同一个头文件被展开两次.比如 a.h 和 b.h 都 include 了 common.h,main.c 又同时 include 了 a.h 和 b.h - 没有保护的话 common.h 会被展开两遍,struct 重复定义.

### 用处二:调试开关

```c
#ifndef DEBUG
#define DEBUG 1
#endif

int main(void) {
#if DEBUG
    printf("DEBUG: x=%d\n", 42);
#endif
    printf("正常输出\n");
    return 0;
}
```

```bash
gcc -o t   t.c              # DEBUG=1,带调试输出
gcc -DDEBUG=0 -o t t.c      # 关掉
```

关掉之后那段代码**连编译出来的二进制文件里都搜不到**(用 `strings t` 找不到).不是运行时跳过 - 它压根没进过编译器,所以不占空间也不占运行时间.

### 用处三:跨平台

```c
#ifdef _WIN32
    #include <windows.h>
    void sleep_ms(int ms) { Sleep(ms); }
#else
    #include <unistd.h>
    void sleep_ms(int ms) { usleep(ms * 1000); }
#endif
```

### 用处四:适配不同板子

```c
#define BOARD_IMX6ULL 1

#if BOARD_IMX6ULL
    #define LED_ADDR 0x020C4068
#else
    #define LED_ADDR 0x4804C130
#endif
```

### 小技巧:`#if 0` 当块注释

```c
#if 0
    ...一大堆暂时不要的代码...
#endif
```

它可以**嵌套**,比 `/* */` 强 - `/* */` 套不了 `/* */`.
