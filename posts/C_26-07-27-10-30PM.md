## strtok函数

```c
#include <stdio.h>
#include <string.h>

int main() {
    const char *sep = "@.";
    char email[] = "fewx@fewx.dev";
    char cp[30] = {0};  // strtok 函数后修改目标字符串    
    strcpy(cp, email);  // 所以如果想保护目标字符串不被修改,最好建立副本
    // char *ret = strtok(cp, sep);
    // printf("%s\n", ret);  // fewx
    // ret = strtok(NULL, sep);
    // printf("%s\n", ret);  // fewx
    // ret = strtok(NULL, sep);
    // printf("%s\n", ret);  // dev
    char *ret = NULL;
    for (ret = strtok(cp, sep); ret != NULL; ret = strtok(NULL, sep)) {
        printf("%s\n", ret);
    }
    return 0;
}
```

> strtok 函数的作用是根据关键字符把目标字符串分割,方法是找到关键字符,然后将关键字符改成'\0'

- 如果没有关键字符,则返回 NULL
- 如果找到关键字符,则返回关键字符前字符串起始位置的地址

- 只需要在第一次调用时传入目标字符串,后面只需要传入 NULL 即可,函数会自动顺着上一次的查找位置查找
