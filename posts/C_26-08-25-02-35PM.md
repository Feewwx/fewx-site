## 联合(共用体)

### 联合类型的定义

- 联合的特征是所有成员共用一块空间,所以联合也叫共用体

```c
#include <stdio.h>

union Un {
    int a;
    char c;
};

int main() {
    union Un u;
    printf("%d\n", sizeof(u));  // 4

    printf("%p\n", &u);    // 0x7fff02436554
    printf("%p\n", &u.a);  // 0x7fff02436554
    printf("%p\n", &u.c);  // 0x7fff02436554

    return 0;
}
```

### 联合的特点

- 联合体的大小是最大的成员的大小

- 联合的使用特点类似与共享单车,同一个车你用了我就用不了,我用了你就用不了

```c
#include <stdio.h>

union Un {
    int a;
    char c;
};

int main() {
    union Un u;
    u.a = 0x11223344;
    u.c = 0x55;
    printf("%d\n", u.a);  // 287454037 -> 0x11223355    
    printf("%d\n", u.c);  // 85 -> 0x55
    return 0;
}
```

上面代码可以体现出我们的系统使用的是小端存储

### 联合大小的计算

```c
#include <stdio.h>

union Un {
    char arr[5];
    int i;
};

int main() {
    printf("%d\n", sizeof(union Un));  // 8
    return 0;
}
```

- 联合也存在内存对齐,规则和结构体一样

- 唯一不同的是联合所有成员共用一块空间,占用的大小只会是最大的成员的大小
