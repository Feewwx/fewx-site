## strcat函数

```c
#include <stdio.h>
#include <string.h>

int main() {
    char arr1[20] = "hello";
    strcat(arr1, " world");
    printf("%s\n", arr1);  // hello world
    return 0;
}
```

> strcat 函数可以在目标字符串后追加内容

- 目标字符串必须足够大
- 目标字符串必须可修改
- 源字符串中必须有\0

> 模拟实现

```c
#include <stdio.h>

char *my_strcat(char *arr1, char *arr2) {
    char *p = arr1;
    while (*arr1 != '\0') {
        arr1++;
    }
    while (*arr1++ = *arr2++) {
        ;
    }
    return p;
}

int main() {
    char arr1[20] = "hello";
    my_strcat(arr1, " world");
    printf("%s\n", arr1);
    return 0;
}
```

- strcat无法自己给自己追加
