## 数据结构的研究内容

怎么用编程解决问题:

```
                                             |-分析问题-|
                                             |
                    |-具体问题抽象为数学模型-|-提取操作对象-|
                    |                        |
                    |                        |-找出操作对象之间的关系-|
                    |                        |
                    |                        |-用数学语言描述-| => 数据结构
怎么用编程解决问题:-|
                    |-设计算法-|
                    |
                    |-编程,调试,运行-|
```

`"程序 = 数据结构 + 算法"`

大家都知道编程中有很多非数值计算问题的数学模型,有很多诸如表,树,图之类的具有逻辑关系的数据

**数据结构**就是一门研究非数值计算的程序设计中计算机的操作对象以及它们之间的关系和操作的学科
